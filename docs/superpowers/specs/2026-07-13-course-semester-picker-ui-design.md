# 课表学期选择器视觉调整设计

## 目标

将“从教务系统抓取课表”的学期选择器从原生列表调整为与课表库、成绩页一致的玻璃浮层，并把交互改为“选择学期后，点击开始同步确认”。

## 视觉结构

- 使用 `GlassPanelStyle.floating` 的悬浮玻璃面板，30px 圆角、顶部拖拽条与现有自适应底部弹层。
- 顶部使用日历图标徽章，标题为“抓取教务课表”，说明为“选择学期后同步普通与实验课程”。
- 学期使用独立玻璃卡片：渐变背景、圆角边框、学期主标题和辅助说明。
- 当前学期卡片带“当前学期”标签，使用主色边框和勾选图标；未选中项使用日历图标。
- 学期格式化为“起始年-结束年 · 上学期/下学期/暑期”；未知尾号保留原始学期文字。

## 交互

1. 读取学期列表后打开选择器，默认选中教务系统标记的当前学期；没有标记时选第一项。
2. 点击卡片仅更新本地选中状态，不发起同步。
3. 底部固定主按钮显示“开始同步”，并展示当前选中学期；无选中值时禁用。
4. 点击主按钮返回所选 `CourseSemester` 并开始现有同步流程；关闭弹层、点击遮罩或返回手势返回 `null`，不发起请求。
5. 选项区域独立滚动，头部与确认按钮固定；保留现有重复同步拦截与错误 Snackbar。

## 范围与兼容性

- 不改变教务接口、课表存储、覆盖规则或同步进度。
- 保留 `CourseTableView.showBottomSheet` 注入点，使组件测试不依赖真实弹层。
- 新增测试覆盖默认选中、切换选项、取消和确认同步传参。

## 验收

1. 选择器视觉元素与现有课表库玻璃面板一致。
2. 打开后当前学期已被选中，切换不会启动网络同步。
3. 取消后同步函数未调用；确认后只调用一次且使用所选学期 ID。
4. 运行目标组件测试与 `flutter analyze`。
