# 1.6.5 发版记录设计

## 目标

将应用版本从 `1.6.4+17` 提升到 `1.6.5+18`，并按 `v1.6.4..HEAD` 的用户可感知变化编写简洁更新记录。

## 版本与文档

- `pubspec.yaml` 更新为 `version: 1.6.5+18`。
- `changelog.md` 顶部新增 `## v1.6.5`，使用“新增 / 优化”面向用户的短条目。
- 不记录提交哈希、关键文件、测试命令、设计文档或 `.gitignore` 等工程维护细节。
- 保留 changelog 中已有的未提交历史整理改动，不回退、不重写旧版本内容。

## 更新内容

1. 成绩查询显示教务系统返回的暑期等非 `-1/-2` 学期，并继续自动隐藏没有成绩的学期。
2. 课表支持选择学期抓取，同时同步普通与实验课程；重新抓取会更新同账号同学期课表。
3. 课表学期选择器升级为玻璃卡片样式，选择后需要确认“开始同步”才会抓取。
4. 课表小组件在本学期没有后续课程时展示学期完成状态，并提示同步新课表。

## 验收

- 版本号为 `1.6.5+18`。
- `v1.6.5` 位于 changelog 顶部，文案只描述用户可感知变化。
- 旧 changelog 未提交修改仍在工作区且内容保持不变。
