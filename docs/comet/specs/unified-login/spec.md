# 统一登录页

## 目的

提供一个简洁、可读的统一登录入口，默认使用验证码登录，同时保留密码登录作为可切换的次要方式。

## 页面结构

- 页面左上角显示应用名「工大盒子」，不显示任何副标题。
- 登录区域不显示插画或装饰图标。
- 登录区域不显示「登录」标题，不显示「支持智慧工大和教务系统账号登录」说明，不显示底部「如智慧工大不可用，将自动切换到教务系统官方页面…」说明。

## 登录方式

- 短信登录开关开启时，页面首次展示为验证码登录：手机号输入，主按钮为「获取验证码」；获取成功后进入验证码输入，主按钮为「登录并继续」。
- 验证码登录与密码登录之间提供一眼可辨的切换（明确标注「验证码登录」与「密码登录」，并体现当前选中项），替换原先无提示的纯文字链接。
- 密码登录包含学号/手机号与密码输入，主按钮为「登录并继续」。
- 短信登录开关关闭时，页面只展示密码登录，不出现验证码登录相关入口。

## 行为不变项

- 验证码登录的获取验证码、倒计时、更换号码、登录成功与失败提示保持原有行为。
- 密码登录失败或需要二次验证时的处理（含切换到验证码登录、切换到教务系统官方登录页）保持原有行为。
- 游客入口在非返回调用方场景显示：可返回时文案为「暂不登录」，否则为「先逛功能」，跳转目标不变；返回调用方场景不显示该入口。
- 登录成功后的凭据保存与页面跳转保持原有行为。
