# 课程班级显示

## Outcome

课程详情弹层（`CourseDetailSheet`）在既有信息行（周数、时间、教师、地点）基础上新增「班级」信息行。班级数据来自教务系统普通课表接口每条课程项中的 `ktmc` 字段（课堂教学班名称，内含合班班级串），随课程数据一起解析、持久化与分享。

## Requirements

### R1 课程数据模型携带班级

- `Course` 新增 `className` 字段（String，默认空串）。
- `toJson` 包含该字段；`fromJson` 读取该字段，缺失时回退空串（兼容旧本地数据、旧分享码、旧导出文件）。
- `sanitizedForShare` 保留班级字段（班级串非隐私），继续剥离 `pcid`。
- `_isSameCourse` 比较不包含班级字段（避免同课程因班级显示差异被判定为不同课程条目）。

### R2 同步解析

普通课表解析（`GetSingleWeekClass.getSingleClass`）从每条 item 读取 `ktmc` 写入 `Course.className`；字段缺失或为空时写空串。实验课表解析保持现状（`className` 为空串）。

### R3 详情弹层显示

- 详情信息列表新增「班级」行，位于「教师」行之后。
- 有值显示内容；空值显示回退文案「暂无班级信息」。
- 班级行允许自动换行完整显示（不参与现有单行缩放逻辑），超长文本不截断。
- 长按该行复制班级内容，提示与现有信息行一致。
- 课表格子卡片内不显示班级。

### R4 复制文本包含班级

「复制课程信息为文本」的输出在「教师」之后增加一行 `班级：<内容>`，空值时写「暂无班级信息」。

## Scenario

- Scenario: 同步后打开带有班级数据的课程详情，详情信息列表出现「班级」条目，内容与教务返回的 `ktmc` 一致，长文本自动换行完整显示，长按可复制。
- Scenario: 打开旧课表数据（无班级字段）或实验课的课程详情，班级条目显示「暂无班级信息」，其余信息行不受影响。
- Scenario: 「复制课程信息为文本」的结果在教师行之后包含 `班级：` 一行。
- Scenario: 带 `className` 的课表生成分享码，旧版本应用导入该分享码不报错（未知字段被忽略）；旧分享码导入新版本，班级显示回退文案。
