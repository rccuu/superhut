# 课程班级显示

## Outcome

课程详情弹层（`CourseDetailSheet`）在既有信息行（周数、时间、教师、班级、地点）基础上展示教务系统返回的课程元信息：班级串、上课人数、学时、考核方式。数据来自教务系统普通课表与实验课表接口的对应字段，随课程数据一起解析、持久化、复制与分享。

## Requirements

### R1 课程数据模型携带课程元信息

- `Course` 拥有 `className`（班级串，String，默认空串）。
- `Course` 拥有 `peopleCount`（上课人数，String，默认空串）、`creditHours`（学时，String，默认空串）、`assessmentType`（考核方式，String，默认空串）。三者统一用 String 承载，解析时把接口的数字值规范为字符串。
- `toJson` 包含上述四个字段；`fromJson` 读取这些字段，缺失时回退空串（兼容旧本地数据、旧分享码、旧导出文件）。
- `sanitizedForShare` 保留上述四个字段，继续剥离 `pcid`。
- `_isSameCourse` 比较不包含这些字段（避免同课程因班级/人数显示差异被判定为不同课程条目）。

### R2 同步解析

- 普通课表解析（`GetSingleWeekClass.getSingleClass`）从每条 item 读取：`ktmc` → 班级串、`peopleNumber` → 上课人数、`zxs` → 学时、`khfs` → 考核方式。
- 实验课表解析（`GetSingleWeekExpClass.getSingleClass`）从每条 course 项读取：`ktmc` → 班级串、`peopleNumber` → 上课人数。
- 班级串取值：实验课的 `ktmc` 可能形如「班级 + 课程号 + 组号」。当 `ktmc` 以该条目的 `kch`（课程号）开头时，截断到 `kch` 之前的部分作为班级串；否则原样保留。
- 班级串与其它元信息的取值都做 trim：字段缺失、为 null 或仅含空白时写空串，不写入空白内容。
- 班级串中的合班逗号串（如「土木工程2307班,智能建造[2303-2304]班」）原样保留，不解析、不拆分、不排序、不改写。

### R3 详情弹层显示

- 详情信息列表含「班级」行（位于「教师」行之后）与「上课人数」「学时」「考核方式」三行。
- 有值显示内容；空值显示各自的回退文案（「暂无班级信息」「暂无上课人数信息」「暂无学时信息」「暂无考核方式信息」）。
- 这些行允许自动换行完整显示（不参与现有单行缩放逻辑），超长文本不截断。
- 长按某行复制该行内容，提示与现有信息行一致。
- 课表格子卡片内不显示这些信息。

### R4 复制文本包含课程元信息

「复制课程信息为文本」的输出在既有行之后依次增加「上课人数」「学时」「考核方式」三行，空值时写各自回退文案。

### R5 分享码携带课程元信息

课表分享码的课程数据包含上述四个字段；旧版本应用导入含新字段的分享码不报错（按未知字段忽略），新版本导入后详情弹层与复制文本显示这些信息。

### R6 已有本地课表的刷新

- 升级到含这些信息的版本后，本地已存在的课表（缓存中无这些字段）不因本变更被破坏或清空。
- 用户在 App 内重新执行一次课表同步后，新同步到的课程条目携带班级串与元信息。

## Scenario

- Scenario: 同步后打开带有班级数据的课程详情，详情信息列表出现「班级」条目，内容与教务返回一致，长文本自动换行完整显示，长按可复制。
- Scenario: 实验课条目的班级行显示剥离课程号后缀后的纯班级串（如「智能建造2304班」）；实验课班级为纯班级串时（如「智能建造[2303-2304]班」）原样显示。
- Scenario: 打开旧课表数据（无这些字段）的课程详情，班级与三行元信息各自显示回退文案，其余信息行不受影响。
- Scenario: 打开有元信息的课程详情，「上课人数」「学时」「考核方式」三行的内容分别等于教务返回的 `peopleNumber`、`zxs`、`khfs`；实验课的「上课人数」等于其分组人数。
- Scenario: 「上课人数」「学时」「考核方式」任一缺失或为空时，对应行显示回退文案，不显示空白，其余行不受影响。
- Scenario: 「复制课程信息为文本」的结果在既有行之后包含「上课人数」「学时」「考核方式」三行。
- Scenario: 带这些字段的课表生成分享码，旧版本应用导入该分享码不报错（未知字段被忽略）；旧分享码导入新版本，缺失字段显示回退文案。
- Scenario: 升级后未重新同步的本地课表仍可正常打开，相关行显示回退文案；用户重新同步一次后，相关行显示真实值。
