# Outcome

统一登录页变得更简洁、更好读：只保留左上角的「工大盒子」标题，去掉副标题、卡片内说明文字和插画；默认展示验证码登录，并让「验证码登录」和「密码登录」两种方式一眼可辨。

# Scope

- 登录页左上角保留「工大盒子」标题。
- 移除标题下方的副标题文字。
- 移除卡片内的「登录」标题、说明文字（「支持智慧工大和教务系统账号登录」）和插画/图标。
- 移除卡片底部的说明文字（「如智慧工大不可用…」）。
- 默认进入验证码登录。
- 用一眼可辨的方式区分「验证码登录」和「密码登录」，替换现在没有提示的文字链接。
- 验证码登录、密码登录、游客入口（先逛功能 / 暂不登录）的现有行为保持不变。

# Non-goals

- 不改登录协议、凭据存储、教务系统官方登录兜底逻辑。
- 不改游客模式的入口与跳转行为。
- 不调整登录页以外的页面。

# Acceptance examples

- A1：打开登录页，左上角只显示「工大盒子」，不再出现副标题。
- A2：登录页不再显示插画、卡片内「登录」标题和两段说明文字。
- A3：首次进入登录页时展示的是验证码登录（手机号输入）。
- A4：页面上能明确看出当前是「验证码登录」，并且有清晰入口可以切到「密码登录」，反之亦然。
- A5：验证码登录、密码登录、游客入口的登录流程与跳转结果和改动前一致。

# Constraints and invariants

- 短信登录开关 `kHutSmsLoginEnabled` 关闭时，页面只展示密码登录，不出现验证码相关入口。
- 不改变任何登录接口调用与凭据读写。

# Decisions

- D1：密码登录保留，改成一眼可辨的切换，而不是删除。理由：用户只抱怨两种方式没有提示、可读性差，没有要求移除密码登录。
